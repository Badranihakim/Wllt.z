Kebijakan Privasi (Privacy Policy)

Terakhir Diperbarui: 31 Oktober 2026

Selamat datang di wllt.z (Personal Finance & Accounting PWA). Kami sangat menghargai privasi dan keamanan data finansial Anda. Dokumen ini menjelaskan bagaimana aplikasi wllt.z mengelola dan melindungi data pribadi Anda.

1. Arsitektur Local-First (Privasi Utama)

wllt.z dibangun dengan prinsip Local-First. Semua data transaksi, dompet, mutasi, dan target anggaran Anda disimpan secara lokal di perangkat Anda menggunakan penyimpanan peramban (IndexedDB). Kami tidak memiliki peladen (server) backend pihak ketiga yang menampung atau memantau transaksi keuangan pribadi Anda.

2. Penggunaan Google OAuth & Layanan Google API

Jika Anda memilih untuk menghubungkan akun Google Anda untuk pencadangan (backup) dan sinkronisasi awan, aplikasi akan meminta izin untuk lingkup (scopes) berikut:

  • Google UserInfo (Profil & Email): Digunakan hanya untuk mengidentifikasi akun Anda dan menampilkan nama serta foto profil pada antarmuka aplikasi.
  • Google Drive (drive.file): Digunakan hanya untuk membuat dan mengelola berkas spreadsheet cadangan yang dibuat secara khusus oleh aplikasi wllt.z di Google Drive Anda. wllt.z tidak memiliki akses ke berkas atau dokumen pribadi lain di Google Drive Anda.
  • Google Sheets (spreadsheets): Digunakan untuk menulis dan menyinkronkan data pencatatan transaksi ke dalam lembar kerja Google Sheets milik Anda sendiri.
Kepatuhan Google API Services User Data Policy:

Penggunaan dan transfer informasi yang diterima dari Google API oleh wllt.z ke aplikasi lain akan mematuhi Google API Services User Data Policy, termasuk persyaratan Limited Use (Penggunaan Terbatas). Data Google Anda tidak pernah dijual atau diserahkan kepada pihak manapun.

3. Penyimpanan dan Keamanan Data

Seluruh komunikasi data antara peramban Anda dengan layanan Google dilakukan secara terenkripsi (HTTPS / SSL/TLS) langsung dari perangkat Anda ke server Google resmi. Kami tidak pernah melihat, menyimpan salinan, atau meneruskan token akses OAuth Anda ke server perantara pihak ketiga.

4. Hak Pengguna & Penghapusan Data

Anda memiliki kendali penuh atas data Anda setiap saat:

  • Hapus Data Lokal: Anda dapat membersihkan seluruh database lokal kapan saja melalui menu Pengaturan aplikasi.
  • Cabut Akses Google: Anda dapat mencabut otorisasi akses wllt.z ke akun Google Anda sewaktu-waktu melalui Google Account Permissions.
  • Hapus Lembar Cadangan: Anda dapat menghapus berkas spreadsheet wllt.z secara langsung dari Google Drive Anda kapan saja.
